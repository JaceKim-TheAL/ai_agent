## 1주차

### SNS 주제 선정 + 계정 최적화(웜업)

#### 1) 인스타그램 계정 개설 
  - 인스타그램 앱을 설치하고 앞으로 운영할 계정을 개설해주세요.

#### 2) 인스타그램 주제 선정 
- 앞으로 운영하고 수익화하고 싶은 계정의 주제를 선정합니다.
- 예) 여행, 요리, 재테크 등

#### 3) 레퍼런스 계정 2~3개 찾기 
- 선정한 주제와 관련된 인기 계정 또는 경쟁 계정 2~3개를 찾아주세요.

#### 4) 1주일 웜업 진행
- 새로 만든 계정을 자연스럽게 활성화하기 위해 매일 약 30분씩 인스타그램을 이용해주세요.

- 선정한 주제의 레퍼런스 계정을 중심으로 콘텐츠를 시청하면서 아래 활동을 5일간 하루 20개씩 진행합니다.

  - 관심 있음: 총 100회 → 하루 20회
  - 좋아요: 총 100회 → 하루 20회
  - 저장: 총 100회 → 하루 20회
  - 관련 계정 팔로우: 하루 20~30개

#### 🚨 한꺼번에 많은 활동을 하지 마세요!
- 신규 계정에서 짧은 시간 내 활동량이 급격하게 늘어나면 비정상적인 활동으로 인식될 수 있습니다. 
- 하루 활동량을 지키면서 5일 동안 천천히 웜업해주세요.

## 4주차

### 고감도 작업물 제출 (공동 포트폴리오)

1) 지금까지 만든 작업물 중 완성도 높은 것 5~10개를 골라 제출해 주세요.
2) 작업물마다 사용한 AI 툴과 제작 과정을 2~3줄로 적어 주세요.
3) 카테고리(숏폼·카드뉴스·상세페이지·홈페이지 등)별로 1~2개씩 고르는 걸 권장해요.

* 클로드에 오파독 MCP를 연결해 숏폼 공장·모션·홈페이지 빌더로 만든 작업물도 낼 수 있어요.
* 우수 작업물은 오파독 × 수강생 공동 포트폴리오에 들어가요.

제출: 작업물 파일 또는 링크 + 툴·과정 설명

## 6주차

### 피그마로 서비스 소개서(회사 소개서) 만들기

내 서비스를 소개하는 소개서 1부를 피그마로 만들어 제출해 주세요. 고객에게 바로 보낼 수 있는 수준이 목표예요.

1) 구성 — 소개(나/회사) · 제공 서비스 · 대표 작업물 · 작업 과정 · 단가표 · 연락처
2) 문구 — 클로드·ChatGPT로 초안을 쓰고 본인 말투로 다듬기
3) 디자인 — 마음에 드는 브랜드 소개서·광고 레퍼런스 3개 이상을 피그마에 올려 놓고, 레이아웃을 참고해 직접 디자인
4) 대표 작업물 이미지는 지금까지 만든 결과물로 채우기
5) PDF로 내보내기

제출: 소개서 PDF(또는 피그마 보기 링크) + 피그마 작업 화면 캡처 1장

※ 이 소개서는 7주차 콜드메일, 12주차 고객 미팅에서 그대로 씁니다.

## 9주차

### 실전 작업물 만들기 (오파독 MCP 활용)

고객에게 바로 보여 줄 수 있는 실전 작업물 3개를 만들어 주세요.

1) 클로드에 오파독 MCP 연결하기 (연결 방법: 오파독 MCP 안내 페이지)
2) 실제 업종 하나를 정해(예: 카페·뷰티·병원) 그 업종 고객이 살 만한 결과물 3개 만들기
   - 숏폼 공장: 광고 숏폼
   - 모션: 모션그래픽 영상
   - 홈페이지 빌더: 랜딩페이지
   (3개 중 2개 이상은 서로 다른 종류로)
3) 작업물마다 "어떤 고객에게, 얼마에 팔지" 한 줄씩 적기

제출: 작업물 3개(파일 또는 링크) + 고객·가격 메모

※ 여기서 만든 작업물은 12주차 고객 미팅에서 시안으로 씁니다.

## 10주차

### 오파독 MCP로 상세페이지 만들기

클로드에 오파독 MCP를 연결해 실제 판매용 상세페이지 2개를 만들어 주세요. 크몽·스마트스토어 고객에게 바로 팔 수 있는 결과물이 목표예요.

1) 상품 정하기 — 실제 브랜드 상품 1개 + 가상 상품 1개 (업종은 자유)
2) 제품 이미지 — 오파독 MCP 이미지 생성으로 제품컷·연출컷 만들기 (실제 상품은 원본 사진을 올려 연출)
3) 구성 — 클로드에게 상세페이지 구성을 맡기기: 후킹 문구 → 문제 제기 → 해결(제품) → 특징 3가지 → 후기·신뢰 → 구매 유도
4) 완성 — 세로 한 장(JPG/PNG) 또는 홈페이지 빌더 페이지로 내보내기
5) 각 상세페이지에 이걸 얼마에 팔지 단가 한 줄 적기

제출: 상세페이지 2개(이미지 또는 링크) + 사용한 프롬프트 캡처 1장

※ 여기서 만든 상세페이지는 크몽·숨고 포트폴리오에 바로 올려 주세요.

## 12주차

### 리드 연락 + 세일즈 미팅 잡기

배정받은 리드(또는 콜드메일 답장 고객)에게 직접 연락해 실제 세일즈 미팅을 잡아 주세요.

1) 연락 전 준비 — 고객 업종에 맞춰 오파독 MCP로 시안 1개를 미리 만들고, 6주차 소개서 준비
2) 전화 걸기 — 첫 연락은 메일보다 전화가 좋아요. 안 받으면 문자 남기고 다시 전화
3) 통화 흐름 — 고객 상황 묻기 → 시안 보여 주기 → 미팅 날짜 잡기
4) 미팅 잡기 — 대면·화상 상관없이 날짜와 시간 확정
5) 미팅 뒤 — 견적서 보내고 계약까지 이어 가기

※ 견적서만 보내고 "하실래요?" 하면 안 돼요. 시안 → 견적서 → 패키지 할인 순으로, 전화로 풀어서 설명해요.
※ 고객 이름·연락처는 가리고 제출해 주세요.

제출: 연락 기록(날짜·방법·결과) + 잡힌 미팅 일정 캡처
(미팅까지 못 잡았다면 연락 시도 기록 5건 이상)
