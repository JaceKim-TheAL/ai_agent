## 1. 자료집 사용 안내

이 자료는 가을 시즌 신메뉴를 소개하는 매장 내 A2 포스터와 인스타그램 이미지를 제작하기 위한 가이드입니다. 메뉴 사진과 계절감을 중심으로 하나의 디자인을 만들고, 각 사용처에 맞게 비율과 배치를 조정합니다.

프롬프트에는 브랜드 매니저, 셰프, 매장 매니저, 디자이너의 검토 관점을 담았습니다. 이는 AI가 브랜드 분위기, 메뉴 표현, 정보 전달, 디자인 완성도를 함께 고려하도록 하는 설정입니다.

---

### 사용 순서

1. 아래 준비 항목을 채웁니다. 대괄호 [ ] 안의 내용은 내 매장과 메뉴 정보로 바꿉니다.

1. 이미지 생성이 가능한 도구에 기본 프롬프트를 입력합니다. 실제 메뉴 사진과 로고, 참고 이미지가 있으면 함께 첨부합니다.

1. 포스터 시안을 먼저 제작하고, 선택한 결과를 참고해 인스타그램용 이미지를 제작합니다.

1. 가장 아쉬운 부분을 골라 후속 프롬프트로 수정합니다.

1. 메뉴명·가격·기간을 확인하고, 포스터는 인쇄 규격에 맞춰 마무리한 뒤 출력합니다. 인스타그램 이미지는 게시 미리보기에서 점검합니다.

## 2. 복사해서 사용하는 프롬프트

### 입력 전 준비할 것

- 매장명·브랜드명: 실제 사용하는 이름을 적습니다.

- 메뉴명: 고객에게 표시할 정확한 메뉴명을 적습니다.

- 메뉴 특징: 맛, 식감, 조리 방식 등 실제 특징을 간단히 적습니다.

- 가격: 실제 판매 가격과 표시 방식을 적습니다. 예: 18,000원.

- 판매 기간: 확정된 기간을 적습니다. 미정이면 ‘표기하지 않음’으로 적습니다.

- 시즌 재료: 실제 메뉴에 사용되는 가을 재료를 최대 3종 적습니다. 밤·호박·사과는 예시이며, 메뉴에 들어가지 않으면 사용하지 않습니다.

- 영문 부제: 사용할 문구를 적거나 ‘메뉴 특징에 맞게 제안 / 사용하지 않음’으로 적습니다.

- 브랜드 색상: 지정 색상이 있으면 적습니다. 없으면 ‘가을 톤으로 제안’으로 적습니다.

- 제작 규격: 포스터는 세로형 A2(420 × 594mm), 인스타그램 이미지는 게시할 용도에 맞는 비율과 픽셀 크기를 적습니다. 실습 예: 세로형 피드 4:5, 1080 × 1350px.

- 첨부 자료: 실제 메뉴 사진, 원본 로고, 브랜드 참고 이미지를 준비합니다. 없으면 ‘없음’으로 적습니다.

### ⭐기본 프롬프트 — 매장 포스터 제작 

아래 내용을 복사하고, 대괄호 안을 바꿔 입력하세요.

```

- 가격: [실제 판매 가격]
- 판매 기간: [확정된 기간 / 표기하지 않음]
- 실제 사용한 시즌 재료: [최대 3종]
- 영문 부제: [문구 / 메뉴 특징에 맞게 제안 / 사용하지 않음]
- 브랜드 색상: [지정 색상 / 가을 톤으로 제안]
- 메뉴 사진: [첨부 / 없음]
- 브랜드 로고: [첨부 / 없음]
- 참고 이미지: [첨부 / 없음]
- 포스터 규격: 세로형 A2, 420 × 594mm
- 인스타그램용 목표 규격: [비율, 가로 × 세로 px]

[작업 방식]
브랜딩/운영 실무팀이 짧게 검토해 합의한 최종안처럼 제작해줘.
다음 네 관점을 함께 반영해줘.
- 브랜드 매니저: 브랜드 분위기와 가을 시즌의 일관성
- 셰프: 실제 메뉴의 구성, 재료, 식감이 정확하게 보이는지
- 매장 매니저: 메뉴명, 가격, 판매 기간이 쉽게 읽히는지

[실무 상황과 최종 합의]
가을 시즌 신메뉴 런칭 주간에 매장 포스터와 인스타그램 이미지로 함께 사용할 디자인이 필요해.
검토 쟁점은 메뉴 사진을 전면에 세울지, 시즌 분위기를 먼저 전달할지야.
최종 방향은 메뉴 탑뷰 사진을 크게 보여주면서 시즌 재료의 질감도 함께 느껴지게 하는 것이야.
메뉴가 주인공이고, 계절감은 색상과 재료, 빛으로 표현해줘.

[장면과 메뉴 표현]
- 메뉴를 위에서 수직으로 내려다본 탑뷰 사진 1컷만 사용
- 중앙에 메뉴를 크게 배치하고 여러 사진을 합친 콜라주는 사용하지 않기
- 주변에는 실제 사용한 시즌 재료를 최대 3종만 자연스럽게 배치
- 재료는 메뉴를 가리거나 음식보다 눈에 띄지 않게 배치
- 실제 메뉴 사진이 있으면 음식 구성, 양, 색상, 그릇, 토핑을 기준으로 삼기
- 제공되지 않은 토핑이나 재료를 임의로 추가하지 않기
- 사진이 없으면 제공한 설명을 바탕으로 콘셉트 시안을 만들고, 실제 메뉴와 대조가 필요하다고 이미지 밖에 알려주기

[구도]
- 세로형 A2 비율의 포스터
- 상단: 메뉴명 타이포그래피, 사용하는 경우 짧은 영문 부제
- 중앙: 메뉴 탑뷰 사진 1컷
- 하단: 가격과 제공된 판매 기간
- 로고: 하단 중앙 또는 우측 하단 중 여백이 자연스러운 위치
- 메뉴명과 가격 사이에 최소 한 줄 이상의 충분한 여백 확보
- 문구가 음식과 겹치지 않게 구성
- 중요한 문구와 로고는 가장자리에서 충분히 떨어뜨리기
- 로고가 없으면 임의로 만들지 말고 배치 공간 비워두기

[연출 방향]
- 앰버와 테라코타를 중심으로 따뜻한 가을 분위기
- 브랜드 지정 색상이 있으면 브랜드 톤을 우선
- 자연광, 부드러운 그림자, 매트한 표면 질감
- 디자인 팔레트는 배경과 글자, 장식 색상을 합쳐 가을 톤 4종 이내
- 음식의 실제 색상은 팔레트에 맞추려고 바꾸지 않기
- 음식의 윤기와 재료 질감은 자연스럽게, 과한 보정은 피하기
- 사진 한 장에서 '가을 한 접시'의 계절감이 느껴지게 표현

[텍스트 처리]
- 메뉴명은 한글 명조 또는 세리프 계열의 느낌으로 크게 표현
- 영문 부제를 사용하는 경우 짧은 이탤릭체로 표현
- 가격과 기간은 쉽게 읽히는 서체와 충분한 대비로 정리
- 한글 메뉴명, 가격, 날짜는 입력한 정보 그대로 사용
- 메뉴명, 선택한 부제, 가격, 기간, 로고 외에 불필요한 문구 추가 금지
- 가격이나 기간이 미확인이라면 임의로 만들지 않기

[완성 기준]
- 메뉴 사진이 가장 먼저 눈에 들어올 것
- 메뉴명과 가격을 쉽게 읽을 수 있을 것
- 실제 제공할 메뉴와 시각적으로 일치할 것
- 계절감이 재료, 색상, 빛에서 자연스럽게 느껴질 것
- 지나가던 사람이 멈춰서 사진을 찍고 싶을 만큼 정돈된 인상일 것
- 인스타그램용으로 재배치해도 유지할 수 있는 명확한 사진·문구 구도일 것

[제외할 것]
- 여러 컷을 합친 메뉴 사진
- 3종을 넘는 시즌 재료
- 단풍잎 일러스트 도배와 스톡 낙엽 이미지

```

## 3. 결과를 다듬는 후속 프롬프트

수정할 이미지를 지정하고 한 번에 한 가지 문제부터 요청하세요. 각 요청에는 유지할 요소와 바꿀 요소를 함께 적습니다.

### 메뉴보다 주변 재료가 눈에 띌 때

```
현재 색감과 문구는 유지해줘. 중앙 메뉴를 더 크게 보여주고, 주변 재료의 크기와 양을 줄여줘. 재료는 실제 사용한 최대 3종만 남기고 메뉴를 가리지 않게 배치해줘. 탑뷰 사진 1컷 구도는 유지해줘.
```

### 가을 분위기가 부족할 때

```
실제 음식의 색상과 구성, 문구는 유지해줘. 배경과 소품을 앰버·테라코타 중심의 따뜻한 톤으로 조정하고 자연광과 매트한 질감을 강화해줘. 단풍잎 장식이나 새로운 재료는 추가하지 마.
```

### 메뉴명이나 가격이 잘 안 읽힐 때

```
메뉴 사진과 전체 색감은 유지해줘. 메뉴명과 가격의 크기, 배경 대비를 높이고 주변 여백을 확보해줘. 두 정보가 사진에 겹치지 않게 하고, 메뉴명과 가격 사이에는 충분한 간격을 유지해줘. 문구 내용은 바꾸지 마.
```

### 실제 메뉴와 다르게 보일 때

```
첨부한 실제 메뉴 사진을 기준으로 음식 구성, 양, 색상, 그릇, 토핑을 바로잡아줘. 현재 배경과 문구 배치는 최대한 유지해줘. 원본에 없는 재료를 제거하고, 탑뷰에서 보이지 않는 부분을 과장하지 마.
```

### 인스타그램 버전에서 요소가 잘릴 때

```
현재 메뉴 사진과 문구, 색감은 유지해줘. 목표 비율 안에 메뉴명, 가격, 기간, 로고가 모두 들어오도록 크기와 간격을 다시 배치해줘. 사진을 늘려 왜곡하지 말고 가장자리 여백을 확보해줘. 작은 화면에서 읽히는 글자 크기는 유지해줘.
```

### 글자가 깨지거나 로고가 왜곡될 때

```
현재 메뉴 사진과 배경, 구도를 최대한 유지한 채 모든 텍스트와 로고를 제거해줘. 상단 메뉴명 공간과 하단 가격·기간·로고 공간은 그대로 비워둬. 새로운 글자나 장식을 추가하지 마.
```

이 경우 편집 도구(예: 피그마)에서 정확한 문구와 원본 로고를 직접 배치합니다. 포스터는 인쇄소가 안내하는 해상도, 재단 여백, 색상 모드와 파일 형식에 맞춰 마무리하세요.

## 4. 배포 전 확인 사항

### 배포 전 체크리스트

- [ ] 메뉴 사진이 탑뷰 1컷으로 구성되어 있고 중심에 명확하게 보인다.

- [ ] 음식의 구성, 양, 색상, 그릇, 토핑이 실제 판매 메뉴와 일치한다.

- [ ] 시즌 재료는 실제 사용한 재료이며 최대 3종이다.

- [ ] 메뉴명, 가격, 판매 기간에 오탈자나 미확인 정보가 없다.

- [ ] 메뉴명과 가격 사이에 충분한 여백이 있고 사진과 문구가 겹치지 않는다.

- [ ] 디자인 팔레트는 가을 톤 4종 이내이며 음식의 실제 색상이 유지되어 있다.
