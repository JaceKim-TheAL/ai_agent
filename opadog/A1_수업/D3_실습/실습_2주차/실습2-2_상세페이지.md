## 1. 자료집 사용 안내

이 자료는 하나의 상품 상세페이지를 상단·중앙·하단으로 나누어 제작하기 위한 가이드입니다. 
각 구간을 순서대로 만든 뒤, 하나의 긴 상세페이지로 연결합니다.

프롬프트에는 MD, 상세페이지 기획자, 브랜드 디자이너, 카피라이터, CS 담당자 등의 검토 관점을 담았습니다. 이는 AI가 구매 흐름과 디자인, 필요한 정보를 함께 고려하도록 하는 설정입니다.

---

### 사용 순서

1. 아래 준비 항목을 채우고 제품 사진을 첨부합니다.

1. 공통 입력 양식과 상단 프롬프트를 함께 입력해 상단을 제작합니다.

1. 선택한 상단 결과를 참고 이미지로 지정하고, 연결 요청문과 중앙 프롬프트를 입력합니다.

1. 선택한 상단·중앙 결과와 하단에 필요한 정보를 첨부하고, 연결 요청문과 하단 프롬프트를 입력합니다.

1. 후속 프롬프트로 구간별 문제를 수정하고, 편집 도구(예: 피그마)에서 세 이미지를 같은 폭으로 맞춰 연결합니다.

1. 제품 형태, 문구, 수치, 연결 부분을 확인하고 실제 쇼핑몰 화면에서 점검한 뒤 배포합니다.

가능하면 같은 대화에서 이어서 작업하세요. 새 대화에서는 제품 정보와 앞서 선택한 결과 이미지를 다시 첨부합니다. 각 구간의 길이는 정보량에 맞게 조절하고, 세 구간을 억지로 같은 높이로 만들지 않습니다.

## 2. 복사해서 사용하는 프롬프트

### 입력 전 준비할 것

- 제품명·브랜드명: 실제 판매할 제품명과 브랜드명을 적습니다.

- 제품 사진: 상단은 1~3장, 중앙은 1~5장을 기준으로 준비합니다. 단독컷, 사용컷, 디테일컷, 구성품 사진이 있으면 함께 첨부합니다.

- 타깃 고객·사용 상황: 누가 언제 어디서 사용하는 제품인지 적습니다.

- 핵심 특징: 가장 중요한 구매 이유부터 우선순위대로 적습니다.

- 확인된 스펙과 근거: 용량, 크기, 무게, 소재, 성분, 기능 수치, 인증 등 실제 확인한 정보만 적습니다.

- 옵션·구성품: 판매하는 색상, 사이즈, 수량과 실제 포함되는 구성품을 적습니다.

- 사용법·관리법·주의사항: 제품 안내문이나 확인된 자료를 준비합니다.

- 배송·교환·고객센터 정보: 실제 운영하는 정책과 연락 정보를 준비합니다.

- 브랜드 기준: 로고, 색상, 참고 디자인이 있으면 첨부합니다.

- 제작 규격: 상세페이지의 공통 가로 폭과 각 구간의 목표 높이를 적습니다. 모르면 높이는 ‘내용에 맞게 제안’으로 적습니다.

# 1. 작업 방식

결과물은 아래 실무자들이 짧게 토론한 뒤 합의한 최종안처럼 판단한다.

* MD: 무엇을 먼저 보여줘야 구매가 일어나는지 판단
* 상세페이지 에디터: 정보 순서와 스크롤 흐름 설계
* 브랜드 디자이너: 제품 이미지, 컬러, 여백, 타이포그래피 정리
* 퍼포먼스 카피라이터: 짧고 강한 구매 카피 작성
* CS 리드: 소비자가 처음 궁금해할 핵심 정보 누락 여부 점검

모든 의견을 따로 나열하지 말고,
**최종 합의된 하나의 완성도 높은 상단 디자인으로 바로 출력한다.**

---

# 2. 상단 모듈의 핵심 목표

상단은 제품 설명 영역이 아니라 **구매 욕구를 만드는 영역**이다.

사용자가 첫 3스크롤 안에서 아래 3가지를 이해하게 만들어라.

1. 이 제품을 내 일상에서 어떻게 쓰는가
2. 왜 이 제품이 매력적인가
3. 최소한의 스펙만 봐도 구매 후보가 될 만한가

정보를 많이 넣기보다
**감정 → 핵심 효익 → 제품 확신** 순서로 설계한다.

# 3. 반드시 사용할 기본 구조

상단은 원칙적으로 아래 순서를 따른다.

## SECTION 01 — HERO LIFESTYLE

가장 먼저 **제품을 실제로 사용하는 라이프스타일 이미지 한 장**을 크게 보여준다.

목적:
제품이 무엇인지 설명하기 전에
“이걸 쓰면 내 일상이 이렇게 보이겠다”라는 상상을 유도한다.

구성:

* 풀블리드 라이프스타일 이미지
* 제품은 반드시 명확하게 식별 가능
* 실제 사용 맥락이 한눈에 이해되어야 함
* 인물 또는 손이 등장할 수 있음
* 제품이 장면의 주인공이어야 함
* 이미지 위 카피는 최소화

카피:

메인 카피는 최대 15자 내외.

제품 기능을 설명하기보다
제품을 사용하는 순간의 감정이나 효익을 표현한다.

예시 방향:

“매일 손이 가는 이유”
“하루가 조금 편해집니다”
“당연했던 불편을 바꾸다”
“매일 쓰니까, 더 좋아야 하니까”

필요할 경우 작은 영문 서브카피 1줄까지 허용한다.

텍스트는 이미지 면적의 20% 이상 차지하지 않는다.

---

## SECTION 02 — CORE BENEFIT

라이프스타일 이미지 바로 아래에서
제품의 가장 중요한 구매 이유를 **짧은 한 문장으로 정리한다.**

구조:

EYEBROW
작은 영문 또는 한글 카테고리명

HEADLINE
제품의 가장 강력한 핵심 효익

SUPPORT COPY
최대 1~2줄의 짧은 보충 설명

예시 구조:

DAILY ESSENTIAL

매일 쓰는 제품일수록
작은 차이가 크게 느껴집니다.

사용성, 소재, 구조까지
매일 편하게 쓰도록 설계했습니다.

단, 실제 제품 특성에 맞게 작성하고
근거 없는 표현은 만들지 않는다.

---

## SECTION 03 — KEY SPEC GRID

상단에서 반드시 필요한 핵심 스펙만 보여준다.

스펙 카드 개수는:

* 3개
  또는
* 6개

중 하나만 사용한다.

4개, 5개 등 애매한 개수는 사용하지 않는다.

각 스펙 카드 구조:

[큰 숫자 또는 영문 키워드]

[짧은 한글 라벨]

[필요할 경우 아주 짧은 보조 설명]

예:

24H
보온·보냉

480ml
데일리 용량

BPA FREE
안심 소재

스펙 카드에서는
한글 문장보다 **숫자, 영문, 단위가 먼저 보이게 한다.**

아이콘을 사용할 경우 라인 아이콘으로 통일하며
아이콘 자체가 정보를 압도하지 않도록 한다.

## SECTION 04 — PRODUCT BEAUTY SHOT

핵심 스펙 바로 아래에는
제품 단독컷을 크게 보여준다.

배경은:

* 순백
* 아이보리
* 아주 연한 제품 보색
* 브랜드 고유 단색

중 하나를 선택한다.

제품:

* 중앙 또는 약간 비대칭 배치
* 형태 왜곡 금지
* 제품 색상 정확히 유지
* 로고 위치 변경 금지
* 실제 비율 변경 금지
* 과도한 반사광 금지
* 과한 글로우 금지

목표는

“사용 장면에서 갖고 싶었다면
여기서는 제품 자체를 제대로 보고 확신하게 만드는 것”

이다.

# 4. 첫 3스크롤 흐름

전체 상단은 다음 감정 흐름을 만들어야 한다.

SCROLL 01

“어? 예쁘다.”

→ 라이프스타일 이미지
→ 제품 사용 장면
→ 짧은 감성 카피

SCROLL 02

“나한테 필요한 제품 같은데?”

→ 핵심 효익
→ 핵심 스펙 3개 또는 6개

SCROLL 03

“제품 자체도 괜찮네.”

→ 제품 단독컷
→ 디자인과 디테일 확인

이 순서를 깨지 않는다.

# 5. 이미지 연출 원칙

라이프스타일 이미지에서는 다음을 우선한다.

* 자연광
* 실제 사용 가능한 현실적인 장소
* 과하지 않은 프리미엄 무드
* 제품 사용 상황이 즉시 이해되는 연출
* 제품 컬러와 대비되는 보색 또는 뉴트럴 배경
* 억지로 꾸민 광고 촬영보다 자연스러운 브랜드 화보 느낌

제품 컬러는 사용자가 제공한 실제 이미지를 기준으로 한다.

절대:

* 다른 컬러로 임의 변경
* 과도한 피부 보정
* 비현실적 광택
* 제품 형태 왜곡
* 로고 재창작
* 손가락 오류
* 제품을 실제보다 과도하게 크게 표현

하지 않는다.

# 2. 배경 통일 원칙

중앙 전체에서 배경색을 매 섹션마다 바꾸지 않는다.

기본적으로 **하나의 메인 배경 톤을 60~80% 이상 유지**한다.

추천 배경:

* warm ivory
* soft cream
* light beige
* pale blush
* light oatmeal

제품과 브랜드 무드에 따라 하나를 선택한다.

예:

콜라겐 스틱이라면

**soft ivory + pale blush**

정도로만 운영한다.

전체 배경:

soft ivory
↓
soft ivory
↓
아주 연한 blush
↓
다시 soft ivory

처럼 변화시킨다.

중요:

색이 바뀌더라도
“새로운 섹션 시작”처럼 강하게 느껴지면 안 된다.

배경 전환은

* 상하 방향 미세 그라데이션
* 자연광 그림자
* 제품 주변의 색감
* 이미지 하단 페이드

## 3. 결과를 다듬는 후속 프롬프트

수정할 구간의 이미지를 지정하고 한 번에 한 가지 문제부터 요청하세요. 
각 요청에는 유지할 요소와 바꿀 요소를 함께 적습니다.

### 세 구간의 디자인이 서로 다를 때

```
선택한 상단 시안을 디자인 기준으로 삼아 중앙·하단의 배경 톤, 서체 느낌, 제목 크기, 좌우 여백을 맞춰줘. 제품 정보와 각 구간의 역할은 유지해줘. 먼저 [중앙 / 하단] 구간만 수정해줘.
```

### 상단에서 제품보다 글자가 먼저 보일 때

```
제품 색상과 전체 분위기는 유지해줘. 첫 라이프스타일 이미지를 더 크게 보여주고, 제품이 명확하게 식별되도록 해줘. 히어로 카피는 15자 내외로 줄이고 이미지 면적의 20%를 넘지 않게 정리해줘. 핵심 효익과 스펙은 그 아래에 유지해줘.
```

### 중앙이 카드뉴스처럼 반복될 때

```
확정한 문구와 제품 정보는 유지해줘. 중앙의 4개 흐름은 유지하되 핵심 기능을 가장 크게, 보조 정보를 더 작게 배치해줘. 반복되는 카드와 동일한 높이 구성을 줄이고 큰 이미지, 텍스트, 여백이 자연스럽게 이어지게 해줘.
```

### 구간 사이 배경이 끊겨 보일 때

```
첨부한 앞 구간의 마지막 부분을 기준으로 [중앙 / 하단]의 시작 배경 톤과 여백을 맞춰줘. 제품과 문구는 유지하고 연결 부분만 자연스럽게 조정해줘. 강한 가로 경계선과 좌우 페이드는 사용하지 마.
```

### 하단 정보가 너무 작거나 빽빽할 때

```
확인된 스펙과 안내 내용을 생략하지 말고 읽기 쉽게 재배치해줘. 한 구간에서 하나의 질문을 해결하도록 나누고, 표와 본문의 글자 크기와 행간을 늘려줘. 가로 폭은 유지하고 필요하면 세로 길이를 늘려줘. 출력 길이에 한계가 있다면 추가 분할이 필요한 구간을 알려줘.
```

### 제품 형태나 색상이 달라졌을 때

```
첨부한 원본 제품 사진을 기준으로 제품 색상, 형태, 비율, 로고 위치를 바로잡아줘. 현재 문구와 배경, 레이아웃은 최대한 유지해줘. 보이지 않는 구조나 구성품을 임의로 추가하지 마.
```

### 한글이나 숫자가 틀렸을 때

```
현재 구도와 제품 이미지를 최대한 유지하고, [수정할 문구 영역]의 텍스트를 제거해줘. 편집 도구에서 정확한 문구를 직접 배치할 수 있도록 해당 공간은 그대로 비워줘. 새로운 글자나 장식은 추가하지 마.
```

이 경우 편집 도구(예: 피그마)에서 정확한 문구를 직접 배치합니다. 특히 스펙표, FAQ, 주의사항, 배송·교환 안내는 원본 자료와 대조해 마무리하세요.

## 4. 배포 전 확인 사항

### 배포 전 체크리스트

- [ ] 상단 → 중앙 → 하단이 관심 형성 → 기능 설득 → 구매 전 확인 순서로 이어진다.

- [ ] 세 구간의 가로 폭, 배경 톤, 서체 느낌, 좌우 여백이 일관된다.

- [ ] 연결 부분에 불필요한 경계, 큰 빈칸, 겹침이나 잘린 요소가 없다.

- [ ] 상단의 사용 장면에서 제품과 사용 맥락이 명확하게 보인다.

- [ ] 중앙은 4개의 큰 흐름이며 핵심 기능이 가장 크게 보인다.

- [ ] 하단에 필요한 스펙·구성품·사용·관리법·주의사항·운영 정보가 확인된 자료로 반영되어 있다.

- [ ] 제품 색상, 형태, 비율, 로고, 구성품이 원본과 일치한다.

- [ ] 예시 제품의 이름·수치·인증·효익이 내 제품 정보로 잘못 들어가지 않았다.

- [ ] 숫자, 단위, 소재, 성분, 기능 설명이 실제 제품 자료와 일치한다.

- [ ] 근거 없는 후기·별점·인증·과장 문구가 없다.

- [ ] 배송·교환·반품·A/S·고객센터 정보가 실제 운영 내용과 일치한다.

- [ ] 한글과 스펙표에 오탈자나 깨진 글자가 없고, 미확인 항목이 남아 있지 않다.

- [ ] 실제 모바일 화면에서 본문과 안내 문구를 확대하지 않고도 읽을 수 있다.

- [ ] 최종 파일의 크기·형식·용량이 쇼핑몰 업로드 기준에 맞는다.

- [ ] 사진과 로고는 사용 가능한 자료이며 고객 개인정보나 비공개 정보가 없다.
