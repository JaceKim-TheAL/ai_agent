## 1. 자료집 사용 안내

이 자료는 자사몰 첫 화면에 크게 노출되는 메인 히어로 배너를 제작합니다.

프롬프트에는 브랜드리드, MD, 퍼포먼스 마케터, 크리에이티브 디렉터의 검토 관점을 담았습니다. 이는 AI가 디자인 조건을 함께 고려하도록 하는 설정입니다.

---

### 사용 순서

1. 아래 준비 항목을 채웁니다. 대괄호 [ ] 안의 내용은 내 브랜드 정보로 바꿉니다.

1. 이미지 생성이 가능한 도구에 복사용 프롬프트를 입력합니다. 로고와 참고 이미지가 있으면 함께 첨부합니다.

1. PC용을 먼저 제작하고, 선택한 결과를 참고해 모바일용을 제작합니다.

1. 결과에서 가장 아쉬운 부분을 골라 후속 프롬프트로 수정합니다.

1. 문구·로고·파일 규격을 확인하고, 실제 쇼핑몰 화면에서 점검한 뒤 배포합니다.

## 2. 복사해서 사용하는 프롬프트

### 입력 전 준비할 것

- 브랜드명: 실제 브랜드명을 적습니다.

- 최대 할인율: 승인된 행사 혜택을 적습니다. 예: 최대 50%. 예시 숫자를 그대로 사용하지 마세요.

- CTA 문구: 방문자의 행동을 유도하는 짧은 문구입니다. 예: 세일 보러 가기.

- PC 배너 크기: 쇼핑몰에서 사용하는 가로 × 세로 px를 확인합니다.

- 모바일 배너 크기: 모바일용 가로 × 세로 px를 별도로 확인합니다.

- 브랜드 색상: 지정 색상이 있으면 색상명 또는 색상 코드를 적습니다.

- 첨부 자료: 원본 로고와 사용 가능한 브랜드 참고 이미지를 준비합니다. 없으면 ‘없음’으로 적습니다.

### ⭐기본 프롬프트

아래 내용을 복사하고, 대괄호 안을 바꿔 입력하세요.

```
자사몰 여름 시즌 세일 메인 히어로 배너 이미지를 제작해줘.

[브랜드 및 배포 정보]
- 브랜드명: [브랜드명]
- 최대 할인율: [최대 OO%]
- CTA 문구: [세일 보러 가기 등 실제 사용할 문구]
- PC 배너 크기: [가로 × 세로 px]
- 모바일 배너 크기: [가로 × 세로 px]
- 브랜드 지정 색상: [색상명 또는 코드 / 없으면 없음]
- 브랜드 로고: [첨부 / 없음]
- 참고 이미지: [첨부 / 없음]

[작업 방식]
브랜딩/MD 실무팀이 짧게 검토해 합의한 최종안처럼 제작해줘.
다음 네 관점을 함께 반영해줘.
- 브랜드리드: 브랜드 톤과 고급스러운 인상
- MD: 할인 혜택의 정확하고 명확한 전달
- 퍼포먼스 마케터: 할인율의 가독성과 CTA의 주목도
- 크리에이티브 디렉터: 사진, 타이포그래피, 여백의 완성도
토론 대화문은 출력하지 말고, 이미지를 제작한 뒤 적용한 디자인 결정만 3줄 이내로 요약해줘.

[실무 상황과 최종 합의]
여름 시즌 세일 시작 2일 전, 실제 배포할 메인 배너가 필요해.
검토 쟁점은 할인율을 먼저 강조할지, 시즌 무드를 먼저 전달할지야.
최종 방향은 이미 정해져 있어.
시즌 무드 사진을 배경에 깔고, 최대 할인율은 우측 하단에 큰 타이포그래피로 배치해줘.

[장면과 구도]
- 해변이나 수영장을 연상시키는 물빛, 햇빛 반사, 오브제가 살짝 보이는 감각적인 스틸컷
- 제품은 직접 노출하지 않기
- 배경 사진은 화면 전체를 채우기
- 좌측 상단에 브랜드 로고 배치
- 우측 하단에 최대 할인율과 CTA 배치
- SALE은 할인율과 경쟁하지 않도록 작고 정돈되게 배치
- 텍스트 주변에는 충분한 여백 확보
- 로고가 없으면 임의로 만들거나 브랜드명으로 대체하지 말고 배치 공간 비워두기

[연출 방향]
- 파스텔 블루 중심, 낮은 채도의 코랄을 보조색으로 사용
- 브랜드 지정 색상이 있으면 브랜드 톤을 우선하고, 충돌하는 코랄은 제외
- 브랜드 톤과 충돌하는 빨강·주황 사용 금지
- 필름 그레인은 은은하게, 채도는 과하지 않게
- 세일 배너이지만 고급 브랜드 캠페인처럼 절제된 인상

[텍스트와 버튼]
로고를 제외한 문구는 아래 3개만 사용해줘.
1. SALE
2. 입력한 최대 할인율: ‘최대’ 표기를 반드시 포함
3. 입력한 CTA 문구

- 할인율 숫자는 입력한 최대 할인율 한 종류만 사용
- SALE과 할인율은 세리프 또는 디스플레이 계열의 서체 느낌으로 표현
- 한글은 고딕 Light 느낌을 기본으로 하되, 작은 화면에서 읽기 어려우면 두께 조정
- CTA 버튼은 배경과 구분되는 단색 채우기
- 추가 부제, 행사 기간, 할인 조건, 광고 문구는 임의로 만들지 않기

[완성 기준]
- 작게 축소해도 할인율과 ‘최대’ 표기가 읽힐 것
- 확대해도 사진과 타이포그래피가 정돈되어 보일 것
- 로고, 할인율, CTA가 가장자리에서 잘리지 않을 것
- 텍스트와 배경의 대비가 충분할 것

[제외할 것]
- 반짝이는 노란 별표
- SUPER MEGA SALE 같은 과장된 문구
- 빨간 원형 할인 스티커
- 제품이 직접 보이는 배경
- 여러 종류의 할인율 숫자
- 복잡한 장식과 불필요한 추가 문구

[이번 출력]
먼저 PC용 배너 1개를 제작해줘.
배너만 단독 이미지로 만들고, 기기 목업이나 PC·모바일을 합친 비교 보드는 만들지 마.
요청한 정확한 크기로 출력할 수 없다면 지원 가능한 비율로 제작하고 실제 출력 크기를 알려줘.
할인율이나 배너 크기 등 필수 정보가 비어 있다면 제작 전에 물어봐.

- 내가 만약 작성 안한 내용은 자유로 직접 상품에 맞는 문구나 정보로 적합하게 제작하게 해. 
```

### 모바일 버전 제작

선택한 PC 결과를 첨부하거나 같은 대화에서 해당 이미지를 지정한 뒤 입력하세요.

```
이 PC 배너를 기준으로 모바일용 배너 1개를 제작해줘.
목표 크기: [가로 × 세로 px]

배경의 분위기, 색상, 문구, 서체 느낌은 유지해줘.
PC 이미지를 단순히 잘라내지 말고 모바일 비율에 맞춰 요소의 크기와 간격을 다시 배치해줘.

모바일 배너만 단독 이미지로 출력해줘.
요청한 정확한 크기로 출력할 수 없다면 실제 출력 크기를 알려줘.

- 내가 만약 작성 안한 내용은 자유로 직접 상품에 맞는 문구나 정보로 적합하게 제작하게 해.
```

## 3. 결과를 다듬는 후속 프롬프트

수정할 이미지를 지정하고 한 번에 한 가지 문제부터 요청하세요. 
각 요청에는 유지할 요소와 바꿀 요소를 함께 적습니다.

할인율이 잘 보이지 않을 때 

```
배경과 전체 색감은 유지해줘. 우측 하단 할인율의 크기와 배경 대비를 높여줘. ‘최대’ 표기도 함께 읽히게 해줘. 다른 문구는 추가하지 마.
```

흔한 세일 배너처럼 보일 때 

```
현재 문구와 배치는 유지해줘. 장식 요소와 색상 수를 줄이고 여백을 늘려줘. 파스텔 블루 중심의 절제된 브랜드 캠페인 분위기를 강화해줘. 할인율의 가독성은 유지해줘.
```

여름 분위기가 부족할 때 

```
로고, 문구, CTA의 위치는 유지해줘. 배경에 물빛, 햇빛의 반사, 수영장 가장자리 같은 여름의 단서를 은은하게 추가해줘. 제품은 노출하지 말고 텍스트 뒤는 복잡해지지 않게 해줘.
```

모바일에서 글자가 작을 때 

```
모바일 버전의 할인율과 CTA를 더 크게 조정해줘. 좌측 상단 로고와 우측 하단 할인율 구도, 기존 색감과 문구는 유지해줘. 가장자리 여백을 확보하고 ‘최대’ 표기도 읽히도록 요소 간격을 다시 조정해줘.
```

CTA가 눈에 띄지 않을 때 

```
나머지 요소는 유지하고 CTA만 수정해줘. 브랜드 팔레트 안에서 배경과 구분되는 단색 채우기를 사용해줘. 버튼 문구의 대비를 높이되 할인율보다 강하게 보이지 않게 해줘.
```

글자가 깨지거나 로고가 왜곡될 때 

```
현재 배경의 분위기와 구도를 최대한 유지한 채 모든 텍스트, 로고, 버튼을 제거한 배경 전용 이미지를 만들어줘. 좌측 상단 로고 공간과 우측 하단 할인율·CTA 공간은 그대로 비워둬. 새로운 글자나 장식은 추가하지 마.
```

이 경우 배경 이미지를 편집 도구(ex. 피그마)로 가져와 정확한 문구와 원본 로고를 직접 배치합니다. 배경 전용 버전도 원본과 달라진 부분이 없는지 확인하세요.

## 4. 배포 전 체크리스트

- [ ] 최대 할인율이 실제 승인된 행사 혜택과 일치한다.

- [ ] ‘최대’ 표기가 빠지지 않았고 작은 화면에서도 읽힌다.

- [ ] SALE, 할인율, CTA에 오탈자나 깨진 글자가 없다.

- [ ] 로고를 넣을 경우 원본과 대조했고, 형태와 비율이 정확하다.

- [ ] 제품 노출, 과장된 장식, 불필요한 추가 문구가 없다.

- [ ] PC·모바일 각각의 최종 크기, 파일 형식, 용량이 쇼핑몰 기준에 맞는다.

- [ ] 실제 쇼핑몰 미리보기에서 로고·할인율·CTA가 잘리지 않는다.

- [ ] CTA 또는 배너 링크가 올바른 세일 페이지로 연결된다.

- [ ] 필요한 행사 조건 안내가 배너 또는 연결 페이지의 적절한 위치에 반영되어 있다.

- [ ] 사용한 로고·사진·참고 자료가 이번 용도로 사용 가능한 자료다.

- [ ] 외부 도구에 입력할 자료에서 고객 개인정보와 공유하면 안 되는 내부 정보를 제외했다.
