# 09. 확정 사항과 변경 이력

| 시점/단계 | 결정 |
|---|---|
| 초기 사업 구상 | 본업 병행, 월 순수익 100만원 시나리오 검토 |
| 전업 사업 설계 | **전업**, 월 순수익 **300만원**, 목표 월매출 500만원으로 변경 |
| 브랜드 운영 | **@standon.agency**를 사업 중심 계정으로 지정 |
| 계정 분리 | **@korea.beyond.battles**는 역사·드라마 취미 계정, 사업과 무관 |
| 첫 영업용 포트폴리오 | 6종 업종별 광고 기획, 첫 상세 제작은 05 IT·생활용품 |
| AUREN ONE 초기안 | 그래파이트 블랙, 어두운 프리미엄 광고, `BEYOND SOUND.` |
| 카피 수정 | `BEYOND` 표현 삭제, **`SOUND IN STYLE.`** 채택 |
| 타깃·비주얼 수정 | 20대 관심을 끄는 **밝은 스카이블루·아이보리 프리미엄 톤**으로 변경 |
| 언어 | 한국어 + 영어 병기 |

## 아직 결정/검증이 필요한 항목
- 최종 이어버드 형태: 기존 이미지에서 스템형과 버튼형이 혼재
- AUREN 상표·로고 상업적 사용 가능 여부
- 6종 이미지의 실제 납품 규격·최종 디자인 일관성 검수
- 실제 서비스 단가와 고객별 제작 소요 시간 검증
- 사업자등록 유형, 세금·보험, 계약서 문구 확정

## 후속 우선순위
1. AUREN ONE 제품 기준 이미지 확정
2. 6종 광고 제품 형태 통일 및 최종 규격 제작
3. @standon.agency 게시용 포트폴리오 구성
4. 첫 30~50개 고객 리스트와 맞춤형 제안 시작
