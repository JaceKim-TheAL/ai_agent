# 05. 6개월 실행 로드맵

> 매출은 실행 목표이지 확정 예측이 아니다.

| 기간 | 월매출 목표 | 핵심 실행 |
|---|---:|---|
| 1개월 | 0~50만원 | 사업 준비, 가격표·계약서, 포트폴리오 6개, 판매 채널 등록 |
| 2개월 | 50~150만원 | 맞춤 제안 50곳, 단건 3~5건 수주 시도 |
| 3개월 | 150~250만원 | 기존 고객 월정액 전환, 정기 1~2곳 목표 |
| 4개월 | 250~350만원 | 정기 3곳 목표, 제작 프로세스 표준화 |
| 5개월 | 350~450만원 | 고가 AI 제품 광고·숏폼 판매, 단가 개선 |
| 6개월 | 500만원 | 정기 고객 5곳 또는 동등한 매출, 순수익 검증 |

## 첫 7일
- [ ] 주력 업종 2개 선택
- [ ] 가격표·제작 범위 확정
- [ ] 사업자등록·세무·계약 체크
- [ ] 포트폴리오 6개 기획
- [ ] 포트폴리오 3개 제작
- [ ] 잠재 고객 30곳 조사
- [ ] 서비스 등록·맞춤 제안 5건

## KPI
월매출, 실제 수금, 견적 발송, 응답률, 계약 전환율, 정기 고객 수, 고객당 작업 시간, 수정 횟수, 원가, 실질 잔여 현금.

## 자금 원칙
초기 준비 예산 약 100~200만원(가정), 개인 생활비 6개월분 별도 확보 권장. 매출이 지연되면 비용과 일정 재설계.
