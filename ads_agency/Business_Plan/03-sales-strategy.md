# 03. 고객 확보 및 영업 전략

## 우선 고객군
1. **온라인 쇼핑몰·뷰티 브랜드**: 제품별 광고 이미지·배너 반복 수요
2. **교육기업·학원**: 강좌·모집용 정보형 카드뉴스
3. **기존 광고대행사·디자인 회사**: 제작 외주 협력
4. 카페·외식·생활용품·B2B는 포트폴리오 확장군

## 초기 월간 활동 가설
| 채널 | 활동 목표 |
|---|---:|
| 크몽·숨고 | 제안/견적 20건 |
| @standon.agency | 작업 사례 12건 게시 |
| 맞춤형 직접 영업 | 40곳 |
| 대행사 외주 제휴 | 10곳 |
| 기존 고객 | 프로젝트 종료 시 후기·소개 요청 |

> 위 숫자는 실험 목표이며 예상 수주율이 아니다. 무차별 대량 DM 대신 고객 상황에 맞춘 소수 제안을 우선한다.

## 잠재 고객 선정 기준
- 제품·서비스는 좋지만 광고 이미지의 통일성이 약함
- 정기 출시·모집·프로모션이 있음
- 담당자가 빠르게 의사결정할 수 있음
- 공개된 연락 경로가 있고 제안이 적절함

## 첫 제안 DM 예시
안녕하세요. AI 기반 광고 콘텐츠를 기획·제작하는 STANDON AGENCY입니다. 브랜드의 제품과 SNS 콘텐츠를 살펴보고, 제품의 매력을 더 선명하게 전달할 수 있는 광고 이미지 방향을 제안드리고 싶어 연락드렸습니다. 제품 광고 이미지·카드뉴스·배너를 기획부터 제작까지 제공하며, 관심 있으시면 관련 작업 사례와 간단한 제안서를 보내드리겠습니다. 감사합니다.

## 대행사 협력 메일 예시
**제목: AI 광고 콘텐츠 제작 외주 파트너 제안 — STANDON AGENCY**

안녕하세요. AI 기반 광고 이미지, 카드뉴스, 쇼핑몰 배너 및 숏폼을 제작하는 STANDON AGENCY입니다. 귀사의 캠페인 제작 업무 중 외부 파트너가 필요한 프로젝트에 협력하고자 합니다. 프로젝트별 단가 또는 월정액 제작이 가능하며 포트폴리오와 견적표를 전달드릴 수 있습니다. 검토 부탁드립니다. 감사합니다.

## 영업 파이프라인
발굴 → 고객별 문제 분석 → 맞춤 제안 → 미팅 → 견적·계약 → 자료 수령 → 제작 → 검수·납품 → 정기 계약 제안.
